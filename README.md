## About

I work in IT support, close to users, systems and integrations: bank files, APIs, SQL and logs.  
Most of my day is finding out *why* something fails, not only *that* it fails.

I now turn that experience into software. My projects start from real support problems, run in the browser when they can, and come with tests and documented technical decisions.

## Current focus

- Moving from support to software development, aiming at remote, international teams
- JavaScript and Node.js, REST APIs and SQL
- Testing, accessibility and technical documentation
- Writing project documentation and case studies in English

## Selected work

### [Arriba Platform](https://arriba.jm.dev.br) — flagship project

Browser-based tools built from real support problems: CNAB 240/400 bank files, CSV validation, a SQL sandbox, and a private Node.js API for authentication and public-data integrations.

Architecture decisions are documented, parsers have automated tests, and accessibility checks run as part of the development workflow.
